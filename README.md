ARES is a mobile agricultural scouting robot designed to detect hazards and other objects in a field.
The robot will move autonomously while using cameras, sensors, GPS, and an FPGA-accelerated CNN
to process its surroundings. The system will have two main modes. In Pre-Scan Mode, the robot will
scan an area, detect objects such as rocks or weeds, and save/ping their locations for later review. In
Real Time Scout Mode, the robot will operate ahead of agricultural equipment and send warnings
when a hazard is detected.
The goal of the project is to combine autonomous movement, object detection, GPS localization,
mapping, and communication into one system that can help make field scouting easier and more
efficient.
